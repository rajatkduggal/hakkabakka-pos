# HakkaBakka POS Native Android companion

This Android app wraps the existing Cloudflare POS website and adds native Android notifications. It does not replace the Cloudflare POS, D1 databases, menu, KOT, or order APIs.

## Notification behaviour
- A new incoming order is shown as a high-priority, audible/vibrating notification. It is not incorrectly promoted to a Live Update because Android's Live Update guidance says these should not be generated by third-party-triggered events.
- After the admin accepts an order and preparation begins, the app can show an ongoing progress notification. On Android 16/API 36 this uses `Notification.ProgressStyle`; older Android versions get an ongoing BigText notification.
- When an order is completed, the progress notification is ended.

## Required Firebase setup (FCM is only the Android delivery transport)
Cloudflare remains the backend and source of truth. Firebase Cloud Messaging is needed to wake a native Android app when it is closed/backgrounded; a PWA Web Push subscription cannot be reused as an Android FCM token.

1. Create or select a Firebase project in the Google account used for HakkaBakka.
2. Add Android app package: `in.hakkabakka.pos`.
3. Download `google-services.json` and place it at `app/google-services.json`.
4. Create a Firebase service account for FCM HTTP v1. Store its JSON privately as a Cloudflare Worker secret; never commit it to GitHub.
5. Cloudflare needs endpoints to register the app's FCM token and dispatch FCM messages on new orders and accepted/preparing/ready/completed status changes.
6. The Android app build can then be produced with the GitHub Actions workflow.

## Build
Open this folder in Android Studio (JDK 17, Android SDK 36), sync Gradle, then Build > Build APK(s).

## Live Update policy
Android Live Updates are intended for ongoing, time-sensitive journeys and should not be used as a generic alert. Incoming orders from a customer use a standard urgent alert. The progress-style Live Update starts only after the admin accepts the order and food preparation begins. Device/OEM eligibility and user settings can still affect whether Android shows the promoted status-bar chip.
